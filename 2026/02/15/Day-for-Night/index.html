Day for Night 调色完全教程

从基础到高级的日转夜调色技术指南

什么是 Day for Night？

Day for Night（日转夜，也称为 La Nuit Américaine）是一种电影制作技术，通过在白天拍摄并在后期调色来模拟夜景效果。这种技术可以避免夜间拍摄的高成本、照明困难和安全问题，同时获得更好的画质和更快的拍摄速度。

经典应用：《教父》、《指环王》、《疯狂的麦克斯：狂暴之路》等众多经典电影都使用了这一技术。

一、前期拍摄准备

1. 最佳拍摄时间

  • 黄金时段（Golden Hour）：日出后30分钟或日落前30分钟，光线柔和，对比度适中
  • 蓝调时段（Blue Hour）：日出前或日落后的20-40分钟，天空呈现深蓝色，最接近夜景效果
  • 阴天：均匀的漫射光，避免强烈阴影，后期处理更容易

2. 相机设置建议

  • 欠曝 1-2 档：降低整体亮度，保留高光细节
  • 使用 ND 滤镜：减少进光量，允许更大光圈获得浅景深
  • 色温设置偏冷：5000K-5500K，或使用钨丝灯白平衡（约3200K）
  • Log 或 RAW 格式：最大化动态范围和后期调整空间

二、调色工作流程

步骤 1：基础曝光调整

  1. 降低曝光值：将整体亮度降低 -1.5 到 -3 档
  2. 压暗高光：Highlights -30 到 -50，避免天空过曝
  3. 提升阴影：Shadows +10 到 +20，保留暗部细节
  4. 降低白色：Whites -20 到 -40
  5. 压暗黑色：Blacks -15 到 -30，增加对比度

步骤 2：色温与色调

  1. 降低色温：-1000 到 -2000K，偏向蓝色调
  2. 调整色调：Tint +5 到 +10，轻微偏绿/青色
  3. 饱和度：降低 -10 到 -20，夜晚色彩较淡

步骤 3：曲线调整（关键步骤）

RGB 主曲线：

  • 压低中间调和高光部分
  • 轻微提升阴影，避免全黑
  • 创建轻微 S 型曲线增加对比

蓝色通道：

  • 提升整体蓝色曲线（向上移动）
  • 在阴影部分增加更多蓝色

红色通道：

  • 轻微降低红色（向下移动）
  • 在高光部分减少红色，模拟月光

步骤 4：HSL 精细调整

色相调整：

  • 橙色向红色偏移 -15
  • 黄色向绿色偏移 +10
  • 蓝色保持或轻微调整 -5

饱和度调整：

  • 橙色 -30 到 -50（肤色去饱和）
  • 黄色 -20 到 -40
  • 蓝色 +10 到 +20（强化夜晚氛围）
  • 青色 +15（增强月光感）

明度调整：

  • 橙色 -20 到 -30
  • 黄色 -15 到 -25
  • 蓝色 -10（避免过亮）

步骤 5：色彩分级（Color Wheels）

  • 阴影（Shadows）：向蓝色/青色偏移，强度 20-40%
  • 中间调（Midtones）：轻微蓝色，强度 10-20%
  • 高光（Highlights）：保持冷色调或添加淡青色，强度 5-15%

三、高级技巧

1. 遮罩与选择性调色

  • 天空分离：使用渐变遮罩或 AI 天空选择，单独调整天空色调和亮度
  • 人物肤色保护：创建人物遮罩，减少面部的蓝色调，保持自然肤色
  • 光源区域：为灯光、窗户等人造光源创建遮罩，保持暖色温，增强夜晚对比

2. 颗粒与质感

  • 添加电影颗粒：10-20 强度，模拟夜间高 ISO 拍摄
  • 轻微锐化：增强细节，但避免过度
  • 降低清晰度：-5 到 -10，营造朦胧夜晚感

3. 渐晕与氛围

  • 边缘渐晕：-15 到 -30，将注意力集中在画面中心
  • 光晕效果：在光源周围添加柔和光晕，增强氛围

4. 动态范围管理

  • 使用区域调色（Power Windows）针对不同区域精细调整
  • 保持一定的对比度，避免画面过平
  • 黑位点设置：确保最暗部分不是纯黑（RGB 10-15）

四、软件特定操作

DaVinci Resolve

  1. Color 页面 → Primaries 面板进行基础调整
  2. Curves 面板进行 RGB 和通道曲线调整
  3. HSL 面板精细调整色相、饱和度、明度
  4. 使用 Qualifier 和 Power Windows 进行选择性调色
  5. 添加节点（Node）分层处理：基础节点 → 肤色节点 → 天空节点 → 光源节点

Adobe Premiere Pro / After Effects

  1. Lumetri Color 面板进行基础调整
  2. 使用 RGB Curves 效果进行通道调整
  3. Color Wheels 调整阴影、中间调、高光色彩
  4. 使用遮罩工具（Mask）进行区域调色
  5. 堆叠多个调整图层（Adjustment Layer）实现复杂效果

Final Cut Pro

  1. Color Board 进行基础色彩调整
  2. Color Curves 进行精细曲线调整
  3. Color Wheels 调整色温和色调
  4. 使用 Shape Mask 和 Color Mask 进行选择性调色

五、常见错误与解决方案

常见问题 表现 解决方案
过度降低曝光 画面全黑，细节丢失 保持阴影细节，使用曲线精细控制
蓝色调过重 画面不自然，偏冷 平衡色温，保护肤色，添加暖光源
对比度不足 画面平淡，缺乏层次 使用 S 曲线增强对比，调整黑白点
天空过曝 白色天空，失去层次 前期拍摄保护高光，后期遮罩压暗天空
肤色不自然 人物面部过蓝或发灰 使用 HSL 或遮罩单独调整橙色，保持温度

六、专业建议

  • 循序渐进：从轻微调整开始，逐步增强效果，避免一步到位
  • 参考真实夜景：观察月光下的实际色彩和光线表现
  • 保持一致性：同一场景的所有镜头使用相同或相似的调色设置
  • 监视器校准：确保显示器已正确校准，避免色彩偏差
  • 多设备测试：在不同显示器和设备上查看效果
  • 保存预设：创建自己的 Day for Night LUT 或预设，提高效率
  • 考虑故事情绪：根据场景情绪调整色调 — 恐怖片可更冷更暗，浪漫片可保留温暖

七、快速参考数值

基础调整推荐值

参数 轻度效果 强烈效果
曝光 -1.5 档 -2.5 到 -3 档
色温 -1000K -1500 到 -2000K
饱和度 -10 -20 到 -30
高光 -30 -50 到 -70
蓝色饱和度 +10 +20 到 +30
橙色饱和度 -30 -40 到 -50

总结

Day for Night 调色是一门需要实践和经验积累的技术。关键在于理解夜晚光线的特性，并通过色彩、对比度和细节的精心调整来重现这种氛围。记住，最好的 Day for Night 效果是那些让观众感觉自然、不刻意的画面。

持续练习和实验是掌握这项技术的唯一途径。尝试不同的参数组合，研究电影作品的调色风格，最终找到属于你自己的 Day for Night 风格。
